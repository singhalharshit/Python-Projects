### 🚀 How to Run the App

You will need **two terminals** open.

#### Terminal 1: The Brain (Backend)
Run this to start the Intelligence Server:
```powershell
python run_backend.py
```
*Wait until you see: "Application startup complete"*

#### Terminal 2: The Face (Frontend)
Run this to launch the Mobile App:
```powershell
cd frontend
flutter run
```
*Select "Windows" or "Chrome" (or Android Emulator if running) when prompted.*
