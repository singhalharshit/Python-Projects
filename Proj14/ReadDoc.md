# Types of Machine Learning
- Supervised -> 1. Regression, 2. Classification
- Unsupervised -> 1. Clustering, 2. Dimension Reduction, 3. Anomaly detection, 4. Association
- Semisupervised
- Reinforcement


## Supervised Learning 

- When you have both input adn output data then you play around with supervised learning
- Two parts of it are -> 1. Regression and 2. Classification 
- We need to understand type of data 1. Numerical (Age,IQ,CGPA) 2. Categorical (Gender,Nationality) etc.
- When you have categorical value it's a classification thing else when with fixed data it's regression

## Unsupervised Learning

- When no output is present with us and only input data is there with me
-   It is of 4 types 1. Clustering, 2. Dimensionality Reduction, 3. Anomaly Detection, 4. Association Reinforcement 


### Batch Learning and Online ML:

- Batch Learning: It's a conventional way to make a model learn offline and in lots. Since the data is very high so we train it on a local system and later we deploy it on server when the model is trained
